Number Guess Game 🎲

A fun number guessing game where players try to guess a randomly chosen 3-digit number. The game provides hints using the Fermi, Pico, Bagels system:

Fermi 🔴 – Correct digit in the correct position.
Pico 🟡 – Correct digit in the wrong position.
Bagels ⚫ – No correct digits.

Modes

🎮 Solo Mode – Try to guess a random number generated by the computer.
👥 Duo Mode – One player enters a number, and the second player guesses it.

How to Play

Choose Solo or Duo mode.
In Solo Mode, the computer picks a number, and you guess it.
In Duo Mode, the first player sets a number, and the second player guesses it.
Receive hints after each guess and try to figure out the number!
